Tester le code ≠ tester la donnée

🧩 Tests unitaires

Une fonction, une transformation isolée, sur des entrées maîtrisées.

🔗 Tests d'intégration

Plusieurs briques ensemble : connexion, chargement, contrats d'API.

🚀 Tests end-to-end

Le pipeline complet, de la source au dashboard.

🧪 Tests de qualité de données

La donnée réelle, en production, à chaque run. Le code peut être parfait et la donnée fausse.

La pyramide de confiance

N4 — Actionnablequi le sait ? store_failures · edr monitor → Slack · rapport Elementary
N3 — Plausibleest-ce normal ? elementary.volume_anomalies · elementary.column_anomalies · elementary.schema_changes_from_baseline angle mort : a besoin d'historique
N2 — Présenteest-elle arrivée ? dbt source freshness angle mort : ne dit rien sur le contenu
N1 — Validela forme est-elle correcte ? unique · not_null · accepted_values · relationships · is_positive · dbt_utils.unique_combination_of_columns · dbt_expectations.expect_column_values_to_match_regex angle mort : ne voit que ce qu'on a anticipé

Les data tests dbt

Un test = une requête SQL qui renvoie les lignes fautives. 0 ligne → PASS.

Generic built-in

unique, not_null, accepted_values, relationships

Packages

dbt_utils, dbt_expectations, elementary — installés via dbt deps

Custom generic

is_positive : une macro {% test %}, réutilisable sur n'importe quelle colonne

Singular

Un fichier .sql dans tests/, pour une règle métier ponctuelle

En contrepoint : unit_tests

Testent la logique d'un modèle dbt sur des données mockées — c'est du test de code, pas de donnée.

Aide-mémoire

Dans l'IDE

  • dbt en 2 minutes : dbt_project.yml, profiles.yml, sources dans dbt/src/models/sources/
  • Compilation : Jinja → SQL, montrer le SQL compilé d'un test dans target/compiled
  • Types de tests dans les YAML + dbt/src/tests/generic/is_positive.sql
  • store_failures (dans dbt_project.yml) → lignes fautives dans le schéma dq_failures
  • Package dbt elementary (modèles + tests dans le warehouse) ≠ CLI edr (rapport + alertes)
  • Optionnel : edr = package Python qui orchestre des macros dbt, requête les tables Elementary, construit un site statique ou envoie des alertes
